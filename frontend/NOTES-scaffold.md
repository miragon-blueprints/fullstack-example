# Frontend scaffold — build notes

Scaffold for the MiraVelo bike-leasing blueprint frontend (FSD + Miragon design
system + shared UI primitives). Node 24.15 / npm 11.12 used locally; `engines`
requires Node >=22.12. `.npmrc` sets `save-exact=true`; every dependency is
pinned to an EXACT version (no `^`/`~`).

## TypeScript 6 specifics (deviation from a naive Vite template)

- `baseUrl` is **deprecated in TS 6** (`TS5101`). Removed it; `paths` (`@/*` ->
  `./src/*`) works without `baseUrl` under `moduleResolution: "bundler"`.
- A composite project reference (`tsconfig.node.json`) can't set `noEmit`
  (`TS6310`) under TS 6. Dropped the `references` wiring: `tsconfig.json` now
  typechecks `src` **plus** `vite.config.ts`/`vitest.config.ts` in one pass.
  `tsconfig.node.json` is kept as a standalone (non-composite) config for the
  Vite/Vitest node context.
- `src/vite-env.d.ts` (`/// <reference types="vite/client" />`) is required
  because `noUncheckedSideEffectImports: true` otherwise rejects the
  `import "./styles/index.css"` side-effect import.

## Integrator notes

- **`Field` (RHF):** wrap a single control; pass `error` as a plain string
  (`errors.field?.message`). It clones the child to wire `id`, `aria-invalid`,
  and `aria-describedby`. Example:
  `<Field label="E-Mail" error={errors.email?.message}><Input {...register("email")} /></Field>`
- **Green is accent-only.** `ci-guard.test.ts` fails the build if `text-gruen`
  or `text-accent` appears in any `.tsx`. Use green for backgrounds/accents only.
- **Toaster:** mount once (already in `__root.tsx`); trigger via `toast()`
  re-exported from `@/shared/ui`.
- Deferred scripts (`lint:fsd`, `lint:deadcode`, `api:generate`, `api:check`,
  `e2e`) are placeholders that echo "not yet configured" and exit 0.
